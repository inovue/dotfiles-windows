# dotfiles-windows — Agent Guide

Windows dotfiles with deterministic deployment. This file is a router: project facts, commands, and pointers.
Global behavior rules (tool matrix, graph-first protocol, read budget) are deployed globally from `configs/agents/GLOBAL_RULES.md` — they are not restated here.

## Project Invariants

- **SSOT**: every master config lives in `configs/`. Never edit deployed copies (`$env:APPDATA`, `~/.claude`, `~/.gemini`, `~/.cursor`) — edit `configs/` then run `just deploy` (app configs) or `just sync-rules` (agent rules & skills).
- **Generated mirrors**: `CLAUDE.md` here is a one-line `@AGENTS.md` pointer generated by `just sync-rules` — edit this `AGENTS.md` instead. `.cursorrules` is intentionally absent (Cursor reads `AGENTS.md` natively; a mirror would double-load every turn and dilute instruction priority).
- **PowerShell**: `justfile` runs `powershell.exe -NoProfile -ExecutionPolicy Bypass`; run standalone `.ps1` with `-NoProfile -NonInteractive -ExecutionPolicy Bypass`. Any `.ps1` containing CJK must be UTF-8 with BOM.
- **Graph present**: `graphify-out/graph.json` exists — graph-first navigation applies (survey: `just audit` + hubs; modify: checkpoint if ≥3 files/security → `just path` → scoped `rg -n` → deploy/update-graph/audit). A post-commit hook auto-rebuilds the graph on every commit.

## Commands (always prefer `just` over hand-built shell)

| Command | Purpose |
| :--- | :--- |
| `just audit` | 4-phase ground-truth audit (tests + SSOT sync + graph health + junk scan). First step for any survey. |
| `just test` | environment suite + security regression + agent_guard v4.1 |
| `just deploy` | deploy `configs/` to user & app directories |
| `just sync-rules` / `just check-rules` | propagate (or verify) agent rules & skills |
| `just graph "<q>"` / `just hubs` / `just neighbors <l>` / `just path <a> <b>` | knowledge-graph queries |
| `just update-graph` | refresh graph once per edit batch |
| `just session-report` | session-log deny rate and read-after-edit (thrash) rate |
| `just install-graph-hook` | install post-commit auto-rebuild hook (once per clone) |
| `just checkpoint` / `just rollback` | git safety net around risky edits |
| `just clean` | remove temp / backup junk |
| `just install` / `just setup-keys` | full machine setup / API key configuration |
